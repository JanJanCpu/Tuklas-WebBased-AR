# Interface wording

- **Section**: the teacher's class roster. Keep **Classes** as the navigation label.
- **Module**: a curriculum group in the lesson library. **Experiment**: one activity within that group.
- **Step**: Predict, Observe or Explain. Keep these POE names and the science text unchanged.
- **Saved**: stored on this device. **Sent**: uploaded to the account so the teacher can see it. Avoid using "offline" as a synonym for an answer that has not been sent.
- **Send Saved Work**: the manual upload action. **Clear Saved Copies**: remove this device's copies; warn that unsent answers will be lost. A teacher's **Reset Progress** removes submitted answers and feedback for the selected scope.
- **Print Slip**: print using a teacher-entered password, without changing it. **New Password**: replace the password and prepare a new slip.
- State action outcomes in button labels. Separate student saves from teacher previews, which do not save student work.
